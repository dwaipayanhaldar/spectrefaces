# Eigenfaces vs SpectreFaces — Linear Carousel

An interactive PCA reconstruction that presents the mean face and the first 24 principal components in a responsive linear carousel.

[Open the GitHub Pages site](https://dwaipayanhaldar.github.io/spectrefaces/)

## Development

```bash
pnpm install
pnpm dev
```

Run `pnpm test`, `pnpm lint`, and `pnpm build` before publishing. The separate `pnpm build:github` command creates the static GitHub Pages artifact.

## Data and attribution

This non-commercial educational visualization derives PCA artifacts from the Flickr-Faces-HQ dataset. Dataset attribution, modification details, and licensing restrictions are recorded in [`public/eigenfaces/ATTRIBUTION.txt`](public/eigenfaces/ATTRIBUTION.txt).
